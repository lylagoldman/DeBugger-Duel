# 🪲🎮👾 DeBugger Duel --> [**Play on itch.io**](https://lylagoldman.itch.io/debuggerduel)

> **DeBugger Duel** is a chaotic, boss-rush 2D action-platformer inspired by the rubber-hose animation of *Cuphead*. Play as **Patchbug**, a lovable glitch tracking unstable, system-threatening code through a dying machine. Your mission? Terminate **Byte-Sized Benny**—a roaring, vintage mainframe determined to execute a total "System Purge" and wipe you out of existence.

---

## 🛠️ Built With

*   **Unity Engine Version:** `Unity 6.6 / 6000.6.x (Silicon)`
*   **Render Pipeline:** Universal Render Pipeline (URP)
*   **Target Platforms:** macOS, Web

## Getting Started (For Developers)
To clone and run this project locally, you will need **Unity Hub** and the correct editor version installed.

### Installation Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/lylagoldman/DeBugger-Duel.git
   ```
2. **Open Unity Hub:**
   * Click **Add** -> **Add project from disk**.
   * Navigate to the cloned folder and select it.
3. **Launch the project:**
   * Make sure you open it using Unity version **6000.6.x** to prevent library conversion errors.
4. **Load the Main Scene:**
   * Navigate to `Assets/_Project/Scenes/` and double-click `Main.unity`.
