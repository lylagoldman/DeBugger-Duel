# De-Bugger Duel

A 2.5D action-platformer built in Unity and C# featuring custom input systems, procedural character generation, and arcade-style gameplay mechanics.

## Tech Stack
- Unity
- C#
- Git/GitHub

## Key Features
- Developed a custom input-mapping system supporting keyboard, Xbox controllers, and 8-bit arcade joysticks.
- Created a spline-extrusion workflow to generate and iterate on the player character's geometry.
- Implemented core gameplay systems including player movement, collision handling, and level interactions.
- Architected reusable C# components to support future combat and platforming mechanics.

## Status
Currently in active development as a personal game development project focused on gameplay programming, input abstraction, and Unity systems design.
